# 🚀 Tuner-2: Вайб-Тюнинг

**Твоя модель — твои правила.**

Tuner-2 — это автономная мультиагентная экосистема для локального дообучения (fine-tuning) LLM. Забудь про сложные настройки и ошибки CUDA — лови вайб прогресса, пока наши агенты тренируют твой ИИ.

## ⚡️ Быстрый старт (One-Command Setup)

Просто вставь эти команды в терминал:

```bash
git clone https://github.com/Ernwr124/Tuner-2.git
cd Tuner-2
bash install.sh
```

После этого просто пиши в любой папке:
```bash
tuner
```

## 🌟 Почему это круто?
*   **Вайб-кодинг архитектура:** Система сама лечит свои зависимости и патчит библиотеки.
*   **Мультиагентный движок:** Командор, Инженер и Дата-сайентист работают за тебя.
*   **Экономия ресурсов:** Обучай модели на 4 ГБ VRAM (например, RTX 2050) или на Apple Silicon.
*   **Стабильный инференс:** Чат после обучения работает по "Ultra Stable" технологии.

## 🏗 Архитектура Агентов
1.  **Commander (Orchestrator):** Планирует миссию.
2.  **Hardware Expert:** Глубокий скан железа.
3.  **Data Scientist:** Валидация данных.
4.  **Stability Agent:** Авто-патчинг и исправление багов.
