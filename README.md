# 🚀 Tuner-2: Autonomous Multi-Agent LLM Fine-Tuning

![Python](https://img.shields.io/badge/python-3.10%2B-blue)
![Architecture](https://img.shields.io/badge/architecture-Multi--Agent-orange)
![Optimization](https://img.shields.io/badge/optimization-Low--VRAM-success)

**Tuner-2** - это продвинутая автономная экосистема для локального дообучения (fine-tuning) больших языковых моделей (LLM). Система построена на базе мультиагентной архитектуры и парадигмы "Vibe-Coding" (Self-Healing Code), что позволяет полностью автоматизировать процесс настройки окружения, подготовки данных и оптимизации гиперпараметров.

Проект создан для того, чтобы разработчики могли сфокусироваться на логике и качестве данных, делегировав рутину по разрешению конфликтов CUDA, управлению памятью и патчингу библиотек интеллектуальным агентам.

---

## 🌟 Ключевые архитектурные решения

*   **Vibe-Coding (Self-Healing Infrastructure):** Динамическое разрешение зависимостей. Система в реальном времени анализирует логи и `traceback` ошибок, автоматически скачивает недостающие пакеты и применяет патчи к проблемным библиотекам "на лету".
*   **Low-VRAM & Hardware-Aware Optimization:** Интеллектуальный профилировщик железа позволяет запускать полноценный fine-tuning (через LoRA/QLoRA) на потребительских видеокартах с 4 ГБ VRAM (например, RTX 2050) и чипах Apple Silicon (Metal API).
*   **Multi-Agent Pipeline:** Децентрализованное управление процессом обучения через изолированных агентов со строгими зонами ответственности.
*   **Ultra Stable Inference Mode:** Гарантированная стабильность генерации после завершения цикла обучения благодаря автоматическому подбору параметров квантования и предотвращению деградации весов модели.

---

## 🏗 Системная архитектура (Multi-Agent Engine)

В основе Tuner-2 лежит взаимодействие четырех автономных узлов:

1.  🧠 **Commander (Orchestrator Agent):**
    *   Маршрутизация пайплайна обучения и определение вектора миссии.
    *   Управление состоянием (State Machine) других агентов.
    *   Сборка итоговых логов и оценка качества сходимости модели.
2.  ⚙️ **Hardware Expert (Profiler Agent):**
    *   Низкоуровневый скан доступных ресурсов (NVML, MPS).
    *   Динамический расчет оптимального `batch_size` и `gradient_accumulation_steps`.
    *   Выбор типа квантования (4-bit/8-bit, NF4) для исключения ошибок `CUDA Out Of Memory`.
3.  📊 **Data Scientist (Data Pipeline Agent):**
    *   Автоматическая валидация, очистка и форматирование датасетов.
    *   Анализ распределения длины токенов.
    *   Оптимизированный паддинг (Dynamic Padding) для ускорения прохождения эпох.
4.  🛡️ **Stability Agent (DevOps/QA Agent):**
    *   Непрерывный мониторинг процесса обучения (`train_loop`).
    *   Перехват предупреждений на уровне PyTorch и системных библиотек.
    *   Применение "горячих фиксов" без прерывания общего цикла обучения.

## ⚡️ Установка (Installation)

Процесс развертывания максимально автоматизирован. Скрипт установит необходимые зависимости и интегрирует CLI-инструмент в среду вашей ОС.

```bash
# Клонирование репозитория
git clone [https://github.com/Ernwr124/Tuner-2.git](https://github.com/Ernwr124/Tuner-2.git)
cd Tuner-2

# Запуск инсталлятора
bash install.sh

## 💻 Использование (Usage)

Для старта пайплайна дообучения перейдите в папку с вашим проектом (где лежат данные) и запустите оркестратор:

```bash
tuner


```

Workflow под капотом:

    🧠 Commander инициализирует сессию и ставит задачи.

    ⚙️ Hardware Expert резервирует видеопамять и настраивает тензорные ядра.

    📊 Data Scientist векторизует датасет.

    🛡️ Запускается изолированный процесс обучения под непрерывным контролем Stability Agent.


🛠 Технологический стек

    Core: Python 3.10+, PyTorch.

    LLM Ecosystem: Hugging Face transformers, peft (LoRA), trl (SFTTrainer), bitsandbytes.

    CLI & Orchestration: subprocess, асинхронное взаимодействие, интеллектуальный парсинг логов.
