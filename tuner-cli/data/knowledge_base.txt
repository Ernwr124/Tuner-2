PROJECT: Tuner-2
DESCRIPTION: Tuner-2 - это модульная платформа для автоматизированного обучения (fine-tuning) больших языковых моделей (LLM) с использованием библиотеки Unsloth.
MAIN GOAL: Упростить процесс обучения моделей для пользователей любого уровня, автоматизируя подготовку данных, выбор железа и написание кода обучения.

CORE AGENTS:
1. Orchestrator: Координирует работу всех агентов, анализирует запросы пользователя.
2. Data Agent: Отвечает за подготовку, очистку и расширение датасетов (JSONL, CSV).
3. Hardware Agent: Анализирует доступную RAM/VRAM и настраивает параметры обучения (LoRA rank, Alpha, Batch Size).
4. Trainer Agent: Генерирует финальный Python-код для обучения (используя Unsloth/MLX).
5. Validator Agent: Тестирует обученную модель и сравнивает её с исходной.

TECHNOLOGIES: Python, Unsloth, MLX, PyTorch, LoRA, QLoRA.
DIRECTORY STRUCTURE:
- tuner-cli: Основной CLI-интерфейс.
- tuner-server: Серверная часть (API).
- data: Место хранения датасетов и базы знаний.
- src/modules: Логика агентов.

IMPORTANT RULES:
- Модель всегда должна отвечать на общие вопросы (например, про столы, небо, погоду) как обычная ИИ-помощница.
- Знания о Tuner-2 используются ТОЛЬКО когда пользователь спрашивает про проект, обучение или работу системы.
- Tuner-2 - это инструмент, а не замена всей вселенной.
